# Accessibility test dependency

`axe.min.js` is axe-core 4.10.3, pinned for reproducible browser checks. It is used only by the test project and is not served by the application.

Source: https://www.npmjs.com/package/axe-core/v/4.10.3
Downloaded from: https://cdn.jsdelivr.net/npm/axe-core@4.10.3/axe.min.js
License: Mozilla Public License 2.0; the distribution retains its license header.

The checks use WCAG 2.0 A/AA and WCAG 2.1 AA rule tags. Automated results do not establish full accessibility conformance or replace assistive-technology testing.
